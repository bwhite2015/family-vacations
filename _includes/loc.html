{%- comment -%} Inline location tag. Use inside a post body: We spent the morning in {% include loc.html id="zion" %}. Renders a link to that location's page and, critically, stamps data-loc="" into the HTML. Layouts scan for that attribute to build the header tag list and the map, so the body text is the single source of truth. Optional: text="..." to override the displayed words. Then on to {% include loc.html id="moab" text="the town" %}. {%- endcomment -%} {%- assign loc = site.data.locations[include.id] -%} {%- if loc -%} {% if include.text %}{{ include.text }}{% else %}{{ loc.name }}{% endif %} {%- else -%} {{ include.text | default: include.id }} {%- endif -%}
